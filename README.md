# dundeezhangv6

The starting point for my next portfolio, copied from dundeezhangv5. Built with Next.js App Router, React, TypeScript, and Tailwind CSS, preserving server rendering and static prerendering for fast initial loads.

Typography uses the variable EB Garamond font through `next/font`, served locally with preloading and `font-display: swap`.

Requires Node.js 20.9 or newer and Bun.

```sh
bun install --frozen-lockfile
bun run dev
```

Run `bun run build` for a production build, then `bun run start` to serve it.
